Тестовое задание на вакансию Back-End разработчик (телеграм бот с заполнением обратной связи за человека)

Скриншоты сохраняются в /img/
База данных (sqlite) создаётся при первом сообщении боту
Ключ бота лежит в .env, вписать свой ключ в переменную BOT_TOKEN

1 - Откройте командную строку от имени администратора.
2 - Используйте команду cd для перехода в папку, где находится код бота. Пример: "cd C:\Путь\к\папке\с\ботом"
3 - Установите все зависимости: "pip install -r requirements.txt " Это установит все необходимые модули и библиотеки.
4 - Запустите бота: "python run.py" 
5 - Для проверки доступности сайта используйте команду: "python check_if_available.py"
6 - Запуск заполнения формы: "python fill_form.py"
Внимание: при запуске fill_form.py бот запускается и обрабатывает только одного пользователя за раз. Не запускайте этот скрипт, если уже работает run.py.
